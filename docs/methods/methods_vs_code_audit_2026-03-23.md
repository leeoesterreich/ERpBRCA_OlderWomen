## CRITICAL ISSUES (Would Likely Trigger Reviewer Rejection)

### C1. Section 07 -- Pseudobulk DE never executes
**Methods claim:** PyDESeq2 DE "was performed" for three comparisons (E1 vs Vehicle, E2 vs Vehicle, E1 vs E2).
**Code reality:** `04_pseudobulk_de.py:230-241` skips any comparison with <2 samples per condition, returning `"SKIPPED"`. All organoid comparisons are n=1 per condition. Script `05_pathways.py:95` then skips GSEA entirely because no DE results exist.
**Impact:** Methods describe results that cannot have been generated by this code.

### C2. Section 02 -- DE statistical test is wrong in main text
**Methods claim:** Main text says DE used "Wilcoxon rank-sum test (min.pct = 0.1, logfc.threshold = 0.25)."
**Code reality:** `08_differential_expression.R:157,181` performs pseudobulk DESeq2 on sample-aggregated counts with design `~ group`. This is a fundamentally different statistical approach.
**Impact:** Reviewers would question whether authors understand their own analysis.

### C3. Section 02 -- DA uses different annotation than documented
**Methods claim:** Both DE and DA used the marker-scoring annotation (`CellTypeByMarker_RatsnRNAseq`) from the primary pipeline.
**Code reality:** DA script `09_differential_abundance.R:64,88,148` loads `seurat_annotated_sctype.rds` and uses `sctype_celltype` because immune cells are absent from the res 0.4 marker-based annotation.
**Impact:** Methods describe a different cell-type source than what was actually used.

### C4. Section 01 -- GSVA gene set count is wrong
**Methods claim:** Main text says GSVA used "five curated estrogen-related gene sets."
**Code reality:** `02_run_gsva.R:101-125` uses **seven** gene sets (adds WikiPathways + 2nd GO BP term).
**Impact:** Factual error in main text.

### C5. Section 04 -- Single-cell GSVA never ran
**Methods claim:** Both pseudo-bulk and single-cell GSVA approaches were performed.
**Code reality:** `run_analysis.sbatch:49` explicitly skips single-cell GSVA for memory reasons. Only pseudobulk was executed.
**Impact:** Methods claim results from an analysis that was not run.

### C6. Section 04 -- Multi-cell-type pathway method systematically misdescribed
**Methods claim:** Script 15 averages SCTransform `data`, uses `min_patients_per_group = 2`, and applies FDR across all pathway-cell-type tests.
**Code reality:** Uses SCT `counts` + sum + CPM + log2 (`15_multicelltype_pathway.R:143-149`), requires 3 patients per group (`:192`), and computes FDR separately within each cell type's curated pathways (`:274-299`).
**Impact:** Three simultaneous errors in one paragraph; would undermine reviewer confidence.

## CROSS-SECTION PATTERNS

### R version discrepancy (Sections 01, 04, 05)
Methods cite R 4.4.1 in multiple places. The repo `environment.yml` pins `r-base=4.3.3`. This needs a single authoritative check and correction.

### "All scripts set seed" claims (Sections 02, 04, 07)
Multiple sections claim all scripts set random seeds. In each case, some scripts do not. Section 07 has the inverse problem: methods claim no seeds, but seeds are present.

### Figure format claims (Sections 02, 04, 06, 07)
Methods consistently overstate or misstate output formats. Actual formats vary by script and should either be standardized or described accurately.

### Environment name confusion (Sections 01, 02, 03)
Methods reference environment names that don't match what sbatch scripts actually activate. Should be verified and unified.

### Package versions unpinned (All sections)
Most sections list versions as "not pinned" or reference an `environment.yml` that doesn't contain the claimed packages. For publication, a `sessionInfo()` / `pip freeze` snapshot would resolve this.
