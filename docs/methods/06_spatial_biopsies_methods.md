# Methods: Spatial Biopsy Analysis (Section 06)

## 1. Data Source and Deconvolution

Six 10x Visium spatial transcriptomics biopsies were obtained from patient HCC22-088, originally generated by Carleton et al. (Carleton et al., [year], [journal]) and symlinked into the current project from the CITEgeist analysis repository. Each biopsy Visium section spans 316–2,251 spots and 2,141–12,251 detected genes. Sample identifiers follow the naming convention HCC22-088-P{1–6}-S1, with one section designated HCC22-088-P3-S1_A. Cell-type deconvolution of each Visium section had been performed upstream using CITEgeist (Chang et al.), which resolved spot-level transcriptomes into nine cell types: Cancer Cells, Immunosuppressive Macrophages (CD163+), Inflammatory Macrophages (CD14+HLA-DR+), T Cell-Interacting Macrophages (CD11c+), CD4 T Cells, CD8 T Cells, B Cells, Endothelial Cells, and Fibroblasts. Deconvolution outputs were stored as cell-type-specific expression layers (pass1 layers) within each AnnData object and loaded from a serialized pickle file (`data/biopsy_adatas.pkl`).

## 2. Spatial Cytokine Visualization

To characterize immunosuppressive cytokine expression in situ, six cytokines were queried across all biopsy sections: IL4, IL10, IL13, TGFB1, TGFB2, and TGFB3. For each sample and each cytokine present in the variable features, spatial expression plots were generated using `sc.pl.spatial()` from scanpy with the viridis colormap (`color_map='viridis'`). Where cell-type-resolved pass1 expression layers were available for macrophage subtypes (identified by the keywords macrophage, CD163, CD14, HLA-DR, or CD11c), layer-specific expression was temporarily assigned as the primary expression matrix and plotted in parallel alongside the unresolved whole-spot expression. Plots were saved as PNG files at 300 DPI to `figures/immune_secretion/`.

## 3. Macrophage Pathway Enrichment

To characterize the functional identity of macrophage subtypes at the pathway level, cell-type-specific expression was extracted from each sample's CITEgeist pass1 layers for each macrophage subtype. For each layer, mean expression was computed across spots, zero-expressing genes were excluded, and the resulting gene scores were rank-ordered by descending expression. Samples with fewer than 100 expressed genes in a given macrophage layer were excluded from downstream pathway analysis.

Two complementary pathway enrichment approaches were applied. For over-representation analysis, the top 200 expressed genes per macrophage subtype per sample were submitted to `gseapy.enrichr()` against three gene set libraries: MSigDB_Hallmark_2020, KEGG_2021_Human, and Reactome_2022 (organism='Human'). Significance was assessed using Benjamini-Hochberg adjusted p-values, and results were filtered to pathways with Adjusted P-value < 0.05. Enrichment analyses were skipped for gene lists containing fewer than 10 genes.

For rank-based enrichment, the full ranked gene score vector (mean expression per gene, sorted descending) was submitted to `gseapy.prerank()` against the same three libraries using 1,000 permutations (`permutation_num=1000`), a random seed of 12345 (`seed=12345`), a minimum pathway gene set size of 5 (`min_size=5`), and a maximum size of 1,000 (`max_size=1000`). The `threads=4` parameter was used for parallelization. Intermediate results from both analyses were serialized as pickle files (`enrichment_results.pkl` and `prerank_results.pkl`) to support figure regeneration without re-running the full computation.

To focus on immune secretory biology, all enrichment and prerank results were filtered at the pathway level to retain only terms containing "TGF" or "interleukin" (case-insensitive) in their name.

## 4. Summary Visualization

Separate summary heatmaps were generated for enrichment results and prerank GSEA results to display interleukin pathway activity in CD163+ (Immunosuppressive) macrophages across all six biopsy samples. For each analysis type, results were restricted to the CD163-containing macrophage subtype and further filtered to a predefined set of interleukin targets: interleukin-1, interleukin-4, interleukin-6, interleukin-10, interleukin-12, interleukin-13, and interleukin-23 (matched as case-insensitive substring patterns). This filtering step explicitly excludes TGF-containing pathway terms at the visualization stage, focusing the final figure on interleukin biology. Reactome pathway identifiers (R-HSA-XXXXXXX suffixes) were removed from term names for readability. For each (pathway, sample) combination, the minimum adjusted p-value across gene set libraries was taken. The resulting matrix was visualized as a heatmap of –log10(Adjusted P-value) using seaborn's `heatmap()` with the Reds colormap, cell borders (linewidths=0.5), and a colorbar labeled '-log10(Adj P-value)'. Figures were saved in both PNG and SVG formats at 600 DPI to `figures/immune_pathways/dotplots/`. Sample labels were abbreviated S1–S6 corresponding to HCC22-088-P1-S1 through HCC22-088-P6-S1.

## 5. Software and Reproducibility

All analyses were performed in Python using the `erp_brca_aging` conda environment. Core packages included scanpy (spatial plotting), gseapy (enrichment and prerank analyses), pandas, numpy, seaborn, and matplotlib. Figure parameters were standardized via a shared `figure_config.py` module enforcing a minimum font size of 14 pt (Arial typeface), a display DPI of 100, and a save DPI of 300 (600 DPI for the summary heatmap). Figures were saved in dual PNG and SVG format. A random seed of 12345 was applied to all stochastic operations, specifically the GSEA prerank permutation step (`seed=12345`).

## Main Text Summary

Six 10x Visium spatial transcriptomics sections from patient HCC22-088 (Carleton et al., [year], [journal]) were analyzed for macrophage-associated cytokine and pathway activity. CITEgeist deconvolution (Chang et al.) resolved spot-level expression into nine cell types including three macrophage subtypes (CD163+, CD14+HLA-DR+, CD11c+). Cytokine expression (IL4, IL10, IL13, TGFB1–3) was mapped spatially using the viridis colormap in scanpy. Macrophage pathway enrichment was performed using the top 200 expressed genes per subtype per sample with gseapy enrichr (MSigDB_Hallmark_2020, KEGG_2021_Human, Reactome_2022; FDR < 0.05) and gseapy prerank (1,000 permutations, seed 12345, min pathway size 5, max 1,000). Results were filtered to interleukin and TGF pathway terms; the final CD163+ macrophage summary heatmap displays interleukin-specific pathways (IL-1, IL-4, IL-6, IL-10, IL-12, IL-13, IL-23), excluding TGF terms.
